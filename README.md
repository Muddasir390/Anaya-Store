# Anaya Abayas — online store

Next.js 16 (App Router) · Supabase (Postgres, Auth, Storage) · Tailwind 4 · Motion. See **SETUP.md**.

Public: home, shop (search/filter/sort), product, wishlist, cart drawer, checkout (COD), order confirmation + WhatsApp, order tracking, about/contact/size guide/FAQ/policies, light/dark theme, SEO (sitemap, robots, JSON-LD).
Admin (`/admin`): dashboard, orders (status + WhatsApp customer), products (image upload), categories, store settings.
